# TickerHop

A Firefox extension that adds a link from the stock you're viewing on Nordnet to its chart on TradingView.

## Supported exchanges

| Nordnet (MIC) | TradingView |
|---------------|-------------|
| `xcse` Copenhagen | `OMXCOP` |
| `xsto` Stockholm | `OMXSTO` |
| `xhel` Helsinki | `OMXHEX` |
| `xosl` Oslo | `OSL` |
| `xnas` Nasdaq | `NASDAQ` |
| `xnys` NYSE | `NYSE` |
| `xase` NYSE American | `AMEX` |
| `xlon` London | `LSE` |
| `xetr` Xetra | `XETR` |
| `xfra` Frankfurt | `FWB` |
| `xber` Berlin | `BER` |
| `xtse` Toronto | `TSX` |
